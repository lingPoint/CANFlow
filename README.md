# CANFlow v3.1.0

CANFlow 是 Windows 桌面 CAN / CAN FD 离线分析工具。多份记录可在独立窗口中对照，多段 BLF 可在同一窗口串联回放；录制工具继续采集时，也可以回看已保存的历史文件。

![CANFlow 多窗口分析](img/workspace-1600.png)


[访问网站](https://canflow.zerox.cc/) · [下载 Windows 版本](https://github.com/lingPoint/CANFlow/releases)


## 工作中的痛点

1. 一次只能分析一个 BLF，难以对比不同记录。
2. 多段文件需要逐个打开，回放分析容易中断。
3. 工程录制期间无法回看历史文件，影响现场问题排查。

## 功能概览

- **多窗口对照**：各窗口独立导入 BLF、配置 DBC、选择信号和控制回放，默认打开两个窗口，可按需增减。
- **多段串联回放**：同一窗口内按最早采集时间依次回放多个 BLF，保留原始时间和文件间空白；不生成合并文件，时间范围重叠的记录需放在不同窗口。
- **历史记录回看**：录制工具继续采集时，可离线分析已完成录制的文件。CANFlow 不负责实时录制，也不读取正在写入的文件。
- **信号选择复用**：项目保存通道、DBC 映射和信号选择；信号组支持替换、追加、导入和导出，切换项目后可复用。
- **波形与测量**：信号使用独立纵轴，通过游标查看数值，或选择真实采样点测量时间间隔。




## 启动

需要 Python 3.10 或更新版本。在项目目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

无需安装 Python 时，可从 [Releases](https://github.com/lingPoint/CANFlow/releases) 下载 `CANFlow.exe`。版本标签（如 `v3.0.1`）会触发 Windows 测试、打包并发布正式版本；分支提交仍生成以提交 SHA 命名的预发布版本。EXE 不包含 BLF 或 DBC 文件，请自行选择本地记录和配置。



## 使用

1. 点击分析窗口或顶部“操作对象”切换当前窗口，蓝色边框与“当前”标识表示选中。通过“新增窗口”“关闭窗口”管理窗口。
2. 点击“导入 BLF”添加记录，“停止”可取消预检；失败或取消不影响已有文件。“文件管理”可查看或清空记录。
3. 点击“配置 DBC”为 CAN 通道指定 DBC，也可先添加通道。修改映射前需停止任务，各窗口配置独立。
4. 点击“添加信号”，搜索并勾选信号。信号组支持保存、替换、追加、导入和导出，所有窗口共享。
5. 点击“开始回放”，用“暂停 / 继续”和“停止”控制当前窗口，各窗口可同时独立回放。无 DBC 时可查看原始报文，追加信号会在回放完成后自动补画。
6. 左侧查看信号及游标值，勾选显示曲线，点击聚焦，默认显示前 3 条。用“自动适配”调整视野；开启“测量间隔”后点击两个采样点测量，用“清除标记”清除当前窗口标记。
7. “显示设置”调整时间格式、主题、网格及播放显示等选项；Ctrl + 滚轮缩放可见轨道纵轴。“原始报文”查看最近 1000 条报文、回放进度并定位时间。
8. 通过“项目”菜单打开或保存当前窗口的 DBC 映射和信号选择。关闭时提示保存未保存项目；退出软件时取消任一提示，会保留全部窗口。

快捷键：Ctrl+Shift+N 新增分析窗口，Ctrl+W 关闭当前窗口，Ctrl+Tab 切换窗口；Ctrl+N 新建当前窗口项目，Ctrl+O 打开项目，Ctrl+S 保存，Ctrl+Shift+S 另存为。

项目文件扩展名为 `.canflow.json`。程序优先使用相对 DBC 路径，并保留绝对路径作为后备；DBC 缺失或定义发生变化时会保留未解析信号并提示用户重新配置。独立信号组文件使用 `.canflow-signals.json`。

信号点缓存放在系统临时目录，退出程序时清理。波形按视野抽样绘制，原始信号点保存在 SQLite 临时缓存中。
