# CANFlow 操作流程与界面优化

本轮沿用现有 Qt 深色界面，以导入、配置、回放、分析为主线。截图由真实 MainWindow 离屏渲染，回放使用脚本生成的 301 帧、3 个信号的非敏感演示数据；不是设计效果图，也不是对用户正在运行的窗口进行操作。

## 流程与发现

1. **首次打开 / 导入：已改善。** 原波形首页只有空图，导入入口藏在配置页。新增常驻步骤提示和直接导入按钮。未导入时禁用开始、暂停、停止，避免点击后才告知缺少文件。见 [空状态](empty-1280.png)。
2. **DBC 与信号配置：已改善。** 原说明要求点击应用，实际勾选后 150ms 自动应用。现在明确说明自动生效、历史补画及回放中延后补画，底部改为“查看波形”。保留没有 DBC 时直接回放原始报文的能力。见 [配置页](config-1280.png)。
3. **回放：已改善。** 将控制按钮从图表标题栏移到两个页面共用的流程栏；任务运行时禁用重复开始和文件清空，补画时禁用暂停及跳转。结束后显示“重新回放”。见 [回放完成](after-waveform.png)。
4. **定位与测量：已改善。** 时间轴、跟随播放和细进度条始终显示，原始报文独立折叠；保留主要波形区域和游标读数。显示设置与报文入口重新命名，避免把时间轴误认为已隐藏。见 [修改前](before-waveform.png) 与 [修改后](after-waveform.png)。

## 视觉与可访问性

沿用现有颜色、组件和波形语义；为键盘焦点增加青色边框，为禁用按钮增加明确状态，并将深色背景上的警告文字改为浅橙色。缩小侧栏最小宽度，为较小窗口留出图表空间。检查了 1600×920 数据视图和 1280×800 空状态 / 配置视图。

截图可确认布局与文案，不能证明屏幕阅读器兼容、所有缩放比例可用或完整可访问性合规。没有进行真实大文件人工操作或 Windows 多屏 DPI 测试。

## 验证

自动化回归覆盖空状态导入入口、无需 DBC 的原始回放、配置与波形跳转、运行及补画期间按钮状态、完成后重新回放，以及收起原始报文时仍保留时间轴和进度。使用 Qt offscreen 测试与实际控件渲染截图检查。

本轮只增量修改 `canflow/app.py`、`tests/test_ui.py` 和本目录文档 / 截图，工作区原有的 store、性能测试及 site 修改未在本轮调整。未提交或推送。
