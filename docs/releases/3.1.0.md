# CANFlow 3.1.0

多窗口数据分析版本，当前为本地构建。

- 顶部统一操作，支持新增、关闭和切换分析窗口；各窗口独立管理 BLF、DBC、信号、回放、缓存和测量。
- 浅色紧凑界面，信号表与网格波形纵向并列展示。文件、DBC、信号和显示设置由顶部打开所属窗口的配置面板。
- 保留原始报文查看、项目/信号组、采样点间隔测量、补画及双文件片段对比。
- 关闭窗口安全停止其任务，关闭软件可逐个保存项目或取消退出。不同窗口写入信号组库前会刷新共享列表。
- 回放不再误标项目为未保存；回放失败保留失败状态。

验证：94 项测试通过，3 项大型压力测试跳过；已检查 1600、1280、1000 像素宽度的实际 Qt 界面。
